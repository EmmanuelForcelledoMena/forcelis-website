# Fotografías de cabecera

Una por página, nombrada por la clave de la página. En cuanto el archivo
existe, la banda oscura de esa página lo muestra velado detrás del titular;
mientras no existe, la banda usa el fondo de tinta con el glifo como marca de
agua. No hay que tocar código.

| Archivo          | Página                  |
| ---------------- | ----------------------- |
| `home.jpg`       | Portada                 |
| `solutions.jpg`  | Soluciones              |
| `platform.jpg`   | Plataforma              |
| `diagnostic.jpg` | Diagnóstico Empresarial |
| `industries.jpg` | Industrias              |
| `about.jpg`      | Nosotros                |
| `contact.jpg`    | Contacto                |

Formato: `.jpg`, `.png` o `.webp`. Tamaño recomendado **2400 × 1350 px** o
mayor, proporción 16:9, con el motivo principal a la DERECHA: la columna
izquierda queda cubierta por el velo del titular. Astro genera las versiones
optimizadas y en `webp` al compilar.

Solo fotografías con licencia para uso comercial. Las que aparecen en los
mockups del manual son parte de una imagen generada y no sirven como fuente. Y
ninguna que muestre un edificio con el logotipo rotulado: no existe tal
edificio, y el sitio no afirma cosas que no son.
