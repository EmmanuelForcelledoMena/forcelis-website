# Fotografías de las seis industrias

Un archivo por sector, nombrado por su clave. En cuanto el archivo existe, la
tarjeta de esa industria lo muestra; mientras no existe, la tarjeta usa un
fondo de tinta con el glifo. No hay que tocar código.

| Archivo                | Sector                    |
| ---------------------- | ------------------------- |
| `manufacturing.jpg`    | Manufactura               |
| `distribution.jpg`     | Distribución              |
| `b2b.jpg`              | Comercio B2B              |
| `trade.jpg`            | Importación y exportación |
| `services.jpg`         | Servicios profesionales   |
| `growth.jpg`           | Empresas en crecimiento   |

Formato: `.jpg`, `.png` o `.webp`. Tamaño recomendado **1600 × 1000 px** o
mayor, proporción 16:10 — la tarjeta recorta al centro. Astro genera las
versiones optimizadas y en `webp` al compilar, así que el original puede pesar
lo que pese.

Solo fotografías con licencia para uso comercial. Las que aparecen en el brand
board son miniaturas de una imagen generada y no sirven como fuente.
